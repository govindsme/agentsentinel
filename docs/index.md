# Agent Sentinel

<span class="site-badge">Version 1.0.0</span> · AI Security &amp; Governance Reference

Agent Sentinel is a continuously maintained, evidence-based knowledge site covering
**AI security, agentic AI, AI governance, AI risk management, privacy, regulations,
control frameworks, and newly discovered AI-related vulnerabilities**.

It supports executives, CISOs, GRC teams, platform teams, engineering teams, product
teams, privacy teams, security teams, procurement teams, and auditors in a common goal:
**understand AI risk, implement and verify controls, and demonstrate auditable governance.**

!!! note "About this site"
    This is a **learning and reference** resource. It explains both *what organisations
    should govern* and *how technical teams can implement, test, and verify the controls*.
    It is **not** legal advice.

## Operating principles

Content on this site follows these priorities:

1. Safety
2. Factual accuracy
3. Source authority
4. Legal & regulatory precision
5. Privacy
6. Defensive security value
7. Auditability
8. Operational usefulness
9. Maintainability
10. Accessibility
11. Performance
12. Visual presentation
13. Publication volume

We clearly distinguish **sourced fact**, **technical observation**, **inference**,
**recommendation**, and **unresolved question**, and we never represent technical
guidance as legal advice.

## Versioning

This repository follows **Semantic Versioning** (SemVer). The current site version is
**v1.0.0** (initial release). Subsequent functional changes advance the version:

- **Major** — breaking architecture or information-architecture changes
- **Minor** — additive sections, new domains, or new regulation coverage
- **Patch** — corrections, factual updates, and non-breaking edits

See [Update History](research/update-history.md) and [Run Reports](research/run-reports.md)
for the change trail.
